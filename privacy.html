Política de privacidad

Última actualización: 29 de octubre de 2026

Gauss es un asistente personal de uso privado. Solo lo usa su autor, y no está disponible para otras personas.

Qué datos usa

  • Google Calendar: Gauss lee, crea y borra eventos del calendario de su autor a pedido de su autor, o para armar un resumen diario.
  • Conversaciones y notas: los mensajes, hábitos y datos que el autor le cuenta a Gauss se guardan en una base de datos local, en su propia computadora.

Con quién se comparten

Los datos no se venden ni se comparten con terceros. Para generar respuestas, el texto de las conversaciones se envía al modelo de lenguaje que use Gauss (por ejemplo, Google Gemini), según las condiciones de ese proveedor.

Uso de datos de Google

El uso de la información recibida de las APIs de Google se ajusta a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso a Google Calendar se puede revocar en cualquier momento desde myaccount.google.com/permissions. Los datos locales se borran eliminando la base de datos de Gauss.
